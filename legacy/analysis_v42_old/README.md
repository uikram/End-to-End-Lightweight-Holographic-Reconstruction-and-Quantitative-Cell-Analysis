value extractor / table writer / number checker (they read `analysis/v42/values.json`). Replaced by
`analysis/v42/compile_results.py`, `update_tables.py` and `check_numbers.py`. Kept only for provenance; they are not
used by anything and expect a repository layout (`Claude outputs/HoloQPI_4.2`) that no longer exists.
